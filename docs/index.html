ぽくミラー for iPhone

iPhone の画面を Windows PC に映して、PC のマウスで操作できるようにするツールです。iPhone 側にアプリは不要です。ESP32 ボードがなくても、画面ミラーリングだけのアプリとして使えます。

ダウンロード（v1.1 / Windows 用 zip・約 170MB）

できること

マウスを動かすiPhone のポインタが動く
左クリックタップ
ドラッグスワイプ
ホイールスクロール

画面の縦／横の切り替えにも対応しています。

必要なもの

  • Windows 10 / 11（64bit）の PC
  • iPhone（PC と同じ Wi-Fi につながっていること）
  • ESP32 ボード（マウスで操作する場合のみ）（1,500 円前後。例: ESP32-DevKitC、Freenove ESP32）
    ※「ESP32-S2」は Bluetooth がないため使えません
  • ボードと PC をつなぐ USB ケーブル（データ通信対応のもの。マウスで操作する場合のみ）

PC のマウスの動きを、USB でつないだ ESP32 ボードが「Bluetooth マウス」として iPhone に伝える仕組みです。そのため ESP32 ボードが必要です。

使い方

  1. zip を展開し、ESP32 ボードを USB で PC につなぎます。
  2. PokuMirror.exe をダブルクリックします（初回はセットアップ画面が案内します）。
  3. iPhone のコントロールセンターから「画面ミラーリング」→「UxPlay-（PC 名）」を選びます。
  4. PC に映った iPhone の画面を左クリックすると操作開始、右クリックで終了です。
